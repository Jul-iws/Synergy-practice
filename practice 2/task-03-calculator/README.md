# Задача 3. Калькулятор

Приложение написано на C# с использованием Windows Forms и .NET 8. Интерфейс создаётся программно, поэтому проект не зависит от файлов конструктора Visual Studio.

## Возможности

- сложение, вычитание, умножение и деление;
- ввод целых и дробных чисел с учётом регионального разделителя;
- очистка и удаление последнего символа;
- обработка деления на ноль и переполнения;
- изменение размера шрифта результата;
- сохранение и загрузка результата.

Сохранённый результат помещается в пользовательский каталог `LocalApplicationData/PracticeCalculator/saved-result.txt`.

## Запуск

Требуются Windows и .NET 8 SDK.

```text
dotnet run --project Calculator.csproj
```
