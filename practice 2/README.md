## Как запустить проекты

Для задач № 3–4 потребуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```text
dotnet run --project task-03-calculator/Calculator.csproj
dotnet run --project task-04-tetris/Tetris.csproj
```

Калькулятор запускается только в Windows. Для задачи № 5 откройте папку `task-05-unity/UnityProject` в Unity Hub и запустите сцену `Assets/Scenes/PracticeScene.unity`. Дополнительные сведения находятся в [`task-05-unity/README.md`](task-05-unity/README.md).

## Загрузка на GitHub

Загрузить на GitHub следует всё содержимое этой папки вместе с файлом `.gitignore`. Каталоги `bin`, `obj` и служебные каталоги Unity в репозиторий добавлять не нужно.
