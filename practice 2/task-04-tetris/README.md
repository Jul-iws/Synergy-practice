# Задача 4. Консольный «Тетрис»

Игра написана на C# и .NET 8 без внешних библиотек.

## Реализовано

- игровое поле 10 × 20 клеток;
- семь стандартных тетрамино;
- автоматическое падение фигур;
- перемещение и поворот с простой коррекцией у стен;
- фиксация фигур, удаление заполненных линий и подсчёт очков;
- завершение игры и повторный запуск.

## Управление

- `←`, `→` — перемещение;
- `↓` — ускоренное падение;
- `↑` или `Space` — поворот;
- `Esc` — завершить игру;
- `Y` — начать новую игру после поражения.

## Запуск

```text
dotnet run --project Tetris.csproj
```

Для корректной отрисовки рекомендуется открыть терминал достаточно большого размера и использовать моноширинный шрифт.
